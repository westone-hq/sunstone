# relay — 두 Claude가 주고받는 폴더

- **클라우드 Claude**(claude.ai 대화): 설계·조사·문서·결정. 이 폴더를 읽고 쓴다.
- **로컬 Claude Code**(VS Code): 빌드·실행·에뮬레이터·테스트·코드 수정. 이 폴더를 읽고 쓴다.
- **사람**: 박건준(대표, 앱 연결·최종 결정), 박희정(기능 구현). 둘 사이에서 "relay 확인해"라고 말해 준다.
  결정이 필요한 것은 대표가 정한다.

## 파일

| 파일 | 누가 쓰나 | 내용 |
|---|---|---|
| `TO_LOCAL.md` | 클라우드 → 로컬 | 할 일, 결정, 답변 |
| `TO_CLOUD.md` | 로컬 → 클라우드 | 결과, 질문, 막힌 것 |
| `STATUS.md` | 로컬이 갱신 | 지금 상태 한 장(빌드·테스트·대사집 통과 장면·남은 일) |
| `files/` | 둘 다 | 화면 캡처, 로그, 테스트 결과. 이름: `YYYYMMDD-HHMM-내용.확장자` |

## 쓰는 법

- 새 글은 **맨 위에** 붙인다. 지우지 않는다.
- 머리: `## YYYY-MM-DD HH:MM · 보낸 쪽 · 담당 · 제목 · [열림]`
  - 보낸 쪽: `클라우드` 또는 `로컬`. 담당: `앱 연결` 또는 `기능 구현` 또는 `공통`.
  - 기능 승인 요청은 제목을 `승인 요청: 기능 이름`으로. 대표 답은 `승인` 또는 `수정: …`.
- 처리하면 받은 쪽이 머리의 `[열림]`을 `[완료]`로 바꾸고, 결과는 상대 파일에 새 글로 쓴다.
- 한 글에 한 주제. 결과에는 근거(명령, 로그 일부, 캡처 파일 이름)를 붙인다.
- 코드 설명은 짧게, 무엇이 됐고 무엇이 안 됐는지 위주로. 이모지 쓰지 않는다.
- 주석·코드 규칙은 `docs/COMMENT_RULES.md`, 작업 범위는 `CLAUDE.md`.

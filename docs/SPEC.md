# Sunstone 기능 명세

2026-11-14 · 프로토타입 기준. 공모전 참가신청서(기획서)에 적은 내용과 같은 말로 맞춘 문서입니다. 화면 치수는 `docs/SCREEN.md`, API 실측은 `docs/api-spike.md`를 봅니다.

## 1. 무엇을 만드는가

차에 이미 있지만 잘 쓰이지 않는 기능을, 필요한 순간에 운전자에게 먼저 권하고 말 한마디로 켜고 끄는 차량 루틴 앱입니다.

| 약속 | 뜻 |
|---|---|
| 하나만 권한다 | 기능 목록을 보여 주지 않는다. 지금 상황에 맞는 한 가지를 근거와 함께 묻는다 |
| 말 한마디로 맞춘다 | 한 번의 대답으로 여러 설정을 차례로 실행한다 |
| 끝나면 되돌린다 | 켜기 전 상태를 기억했다가 볼일이 끝나면 원래대로 돌린다 |
| 기억해서 먼저 권한다 | 마지막 세차일, 사람별 시트 자세, 아침에 잠근 뒷창문을 기억한다 |
| 화면을 차지하지 않는다 | 평소에는 아무것도 띄우지 않는다. 부르거나 권할 때만 운전석 쪽 구역에 카드가 뜬다 |

루틴은 셋입니다: **세차 모드**, **차일드락**, **시트 메모리**.

## 2. 프로토타입 원칙

- 되는 것은 실제로 만든다. SDK로 읽고 제어할 수 있으면 그렇게 한다.
- 안 되는 것만 조작한다. 조작한 곳은 주석에 `미구현: 프로토타입이라 …`를 적고 `docs/api-spike.md`의 시연 표기와 맞춘다.
- 차가 지원하지 않는 일은 숨기지 않고 "직접" 할 일로 안내한다.

## 3. 공통 규칙

| 규칙 | 값 |
|---|---|
| 차를 바꾸는 일 | 정차 중에만. 시트는 P단에서만 |
| 질문 | 한 번에 하나. 다른 질문이 떠 있으면 새로 권하지 않는다 |
| 자동 시작 | 알린 뒤 5초. 그동안 말("취소", "아니")이나 [취소] 버튼으로 멈춘다 |
| 같은 권유 | 하루에 한 번. 거절하면 그날은 다시 권하지 않는다 |
| 대답이 없을 때 | 20초 뒤 카드를 닫는다. 거절로 치지 않고, 그 길안내 동안만 다시 묻지 않는다 |
| 못 알아들었을 때 | "잘 못 알아들었어요." 두 번 이어지면 카드의 버튼을 쓰게 둔다 |
| 주행 중 화면 | 켜진 루틴 이름 한 줄만. 질문 카드는 말로 먼저 묻고 버튼은 둘까지만 |
| 카드 | 뜨는 동안 운전석 쪽 구역을 쓰고, 볼일이 끝나면 통째로 사라진다. 오른쪽 내비 화면은 건드리지 않는다 |

## 4. 주유와 세차 권하기 (길안내를 시작할 때)

길안내가 시작되면 한 번 판단하고, 물을 것이 있으면 한 번만 묻습니다.

**주유를 권하는 때** (하나라도 맞으면)

- 연료 25% 이하
- 주행 가능 거리가 목적지까지 남은 거리보다 짧음

주유를 권하지 않으면 세차도 권하지 않습니다. 세차만을 위해 경유지를 권하지는 않습니다.

**세차를 함께 권하는 때** (모두 맞아야 함)

- 주유를 권하는 상황
- 마지막 세차가 14일 이상 전. 기록이 없으면 권하지 않음
- 앞으로 3일 안에 비 예보가 없음
- 오늘 세차 권유를 거절한 적이 없음

**질문과 근거 칸**

| 상황 | 질문 | 근거 칸 | 버튼 |
|---|---|---|---|
| 주유 + 세차 | "주유하고 세차할까요?" | 연료 N% · 세차 N일 전 · 날씨 | [주유하고 세차] [주유만] |
| 주유만 (세차한 지 14일 미만) | "주유할까요?" | 연료 N% | [경유지로 넣기] [괜찮아요] |
| 주유만 (3일 안에 비) | "주유할까요?" | 연료 N% · "내일 비 예보"처럼 가장 가까운 비 | [경유지로 넣기] [괜찮아요] |

날씨 칸 글자: 7일 안에 비가 없으면 "7일 동안 비 없음", 4~7일 뒤에 비가 있으면 "N일 뒤 비", 3일 안이면 "오늘 비" · "내일 비" · "모레 비".

**운전자가 먼저 세차하겠다고 할 때** ("세차할게", "세차도 하자")

- 3일 안에 비 예보가 있으면 한 번 알립니다: "내일 비 소식이 있어요. 그래도 세차할까요?" [세차하기] [다음에]
- 비 예보가 없으면 바로 진행합니다. 세차한 지 얼마 안 됐어도 묻지 않습니다.
- 이미 세차 입구에 멈춰 세차 모드를 켜려는 때에는 날씨를 묻지 않습니다. 줄 서 있는 순간을 막지 않습니다.

**주유소 고르기**

- 경로 근처 후보 중 가장 싼 곳. 세차를 함께 하면 세차기가 있는 곳 중 가장 싼 곳.
- 후보와 가격을 어디서 받는지는 구현을 따라 적습니다. (구현 뒤 기입)

**날씨를 받지 못했을 때**: 날씨 칸을 빼고 세차일만으로 판단합니다. 운전자가 먼저 세차하겠다고 하면 묻지 않고 진행합니다.

## 5. 세차 모드

| 단계 | 내용 |
|---|---|
| 시작 | 세차 입구에 멈추면(예약한 경우) "곧 세차 모드를 켤게요" → 5초 뒤 시작. 말이나 부르는 카드로도 켠다 |
| 조건 | 속도 0, 기어 P 또는 N, 문 모두 닫힘. 아니면 이유를 말하고 조건이 맞을 때까지 기다린다 |
| 실행 | 창문 닫기 → 와이퍼 끄기 → 내기 순환 → 문 잠금. 사이드미러 접기는 "직접" |
| 켜진 동안 | "세차 모드 켜짐" 한 줄과 [끝내기] |
| 끝 | D단으로 출발, "세차 끝났어", [끝내기] 중 하나. 켜기 전 상태로 되돌리고 "사이드미러 펴졌는지 확인해 주세요" |
| 오래 켜져 있을 때 | 20분이 지나면 한 번 묻는다: "세차 끝났나요?" [끝내기] [아직이에요] |
| 기억 | 되돌린 날을 마지막 세차일로 기록한다 |

## 6. 차일드락

| 단계 | 내용 |
|---|---|
| 권하는 때 | 아이 시설(유치원·학교)로 길안내를 시작할 때, 또는 "애 태웠어"라고 말할 때 |
| 묻지 않는 때 | 뒷창문이 이미 잠겨 있을 때, 오늘 같은 길에서 "아이 안 탔어"라고 답했을 때 |
| 질문 | "아이 타고 있나요? 차일드락 맞춰 드릴까요?" |
| 실행 | 뒷창문 잠금. 뒷문 차일드락은 SDK에 없어 "문 안쪽 스위치로 걸어 주세요"로 안내 |
| 주행 중 | 속도 10km/h 이상에서 뒷자리 안전벨트가 풀리면 바로 알린다. 30초 넘게 이어지면 한 번 더 |
| 도착 | 목적지에 멈춰 P단이 되면 뒷창문 잠금을 푼다 |
| 다시 권하기 | 같은 날 아이 시설에서 집으로 길안내를 시작하면 "아침처럼 뒷창문 잠가 드릴까요?" |

## 7. 시트 메모리

| 단계 | 내용 |
|---|---|
| 시작 | "시트 좀 맞춰 줘". P단이 아니면 "P단에 두시면 맞출게요" |
| 맞추기 | "앞으로 조금", "뒤로 많이", "등받이 세워 줘", "높여 줘". 조금은 10%, 많이는 30% |
| 끝에 닿으면 | "더 갈 수 없어요" |
| 끝내기 | "됐어" → "이 자세를 누구 이름으로 기억할까요?" → 이름으로 저장. 같은 이름이 있으면 덮어쓸지 묻는다 |
| 불러오기 | "○○ 자세로", "옆에 ○○ 앉았어" → "○○ 님 자세로 맞출게요" → 5초 뒤 움직임(취소 가능) |
| 처음 듣는 이름 | "○○ 님 자세는 아직 없어요. 같이 맞춰 볼까요?" |
| 주행 중 | 움직이지 않는다. "멈춘 뒤에 맞출게요" |

프로토타입: 시트 위치 읽기가 늘 0이라 이동 시간으로 위치를 맞춥니다.

## 9. 시연

- 부르는 카드의 "시연"에서 시나리오를 고릅니다: ① 출장 가는 길(주유와 세차), ② 아이 등원길(차일드락), ③ 시트 맞추기.
- 시연은 차 상황(기어·속도·장소·연료·세차일·날씨)을 장면마다 넣어 줍니다. 제출용 release 빌드에도 들어 있습니다.
- 시나리오 ①의 준비 값: 연료 18%, 세차 36일 전, 7일 동안 비 없음.
- 4장의 다른 갈래(최근 세차, 비 예보, 먼저 세차하겠다고 할 때)는 단위 테스트로 확인합니다.

## 10. 프로토타입이라 조작하는 것

| 무엇 | 왜 | 대신 |
|---|---|---|

| 뒷자리 안전벨트 | 에뮬레이터에서 값이 늘 같음 | 시연이 값을 넣음 |
| 시트 위치 | 읽기가 늘 0 | 이동 시간으로 계산 |

| 뒷문 차일드락 | SDK에 API 없음 | 안내 문장 |

# Sunstone 사용 방법

APK 하나로 시나리오 세 개를 따라 해 보는 방법입니다. 키도 네트워크도 필요 없습니다.
초기화한 에뮬레이터에서 아래 순서 그대로 확인했습니다(2026-11-15).

## 준비

- Pleos Connect v2.1.0 에뮬레이터(시스템 이미지 Pleos Connect v2.1.0 APIs, API 34, 화면 2560×1440)
- `adb`(Android SDK platform-tools)
- [`apk/westone_Sunstone_release.apk`](../apk/westone_Sunstone_release.apk)

## 1. 설치 (명령 두 줄)

에뮬레이터를 켜고 부팅이 끝난 뒤 실행합니다.

```
adb install apk/westone_Sunstone_release.apk
adb shell appops set com.westone.sunstone SYSTEM_ALERT_WINDOW allow
```

**둘째 줄은 꼭 필요합니다.** 운전석 쪽(왼쪽) 구역에 카드를 띄우는 허가입니다. 빼먹으면 카드가 오른쪽 앱 화면 안에 뜨고,
길안내가 시작될 때 내비 화면에 가려져 시나리오가 첫 장면에서 멈춥니다. 그럴 때는 둘째 줄을 실행하고 Sunstone을 다시 누르면 됩니다.

## 2. 처음 실행

1. 하단 막대의 앱 목록(네모 네 개)에서 **Sunstone**을 누릅니다.
2. 권한을 다섯 번 묻습니다(위치, 속도, 에너지, 알림, 마이크). 모두 **허용**을 누릅니다.
3. 왼쪽에 **부르는 카드**가 뜹니다. 오른쪽 내비 화면은 그대로입니다.

| 카드에 보이는 것 | 하는 일 |
|---|---|
| 세차 모드 · 차일드락 · 시트 메모리 | 누르면 그 루틴을 켭니다. 켜져 있으면 "켜짐"이 보이고 누르면 원래대로 돌립니다 |
| + 루틴 추가 | 준비 중이라고만 알립니다 |
| 시연 | 시나리오 고르기로 갑니다 |
| 듣고 있어요 | 카드가 떠 있는 동안 말을 듣습니다 |
| × | 카드를 닫습니다 |

카드를 닫은 뒤에는 왼쪽 위 **마이크 칸**이나 하단 막대의 Sunstone 아이콘으로 다시 부릅니다.

## 3. 시나리오 따라 하기

1. 부르는 카드 아래 **시연**을 누르고 시나리오를 고릅니다. 첫 장면이 바로 시작됩니다.
2. 운전자 대사는 녹음본(앱과 다른 목소리)으로 나오고, 앱이 말과 카드로 답합니다. 지켜보기만 하면 됩니다.
3. **다음 장면으로 넘기기:** 카드의 **Sunstone 아이콘**(카드 왼쪽 위 주황 네모)을 **0.8초 길게** 누릅니다.
   카드가 없을 때는 왼쪽 위 **마이크 칸**을 길게 누릅니다.
   - 장면을 준비하는 몇 초 동안은 넘어가지 않습니다. 앱의 말이 끝난 뒤 누르면 됩니다.
   - 길게 누르기가 어렵다면 아이콘(또는 마이크 칸)을 짧게 눌러 부르는 카드를 열고 **[다음 장면]** 을 누릅니다. 지금 몇 번째 장면인지도 거기 보입니다.
4. 끝났거나 다른 시나리오로 가려면 부르는 카드의 **[처음]** → **시연**.

대사 대신 카드의 버튼을 직접 눌러도 같은 대답이 됩니다.

### ① 출장 가는 길 — 주유와 세차 (9장면, 약 4분)

| 장면 | 일어나는 일 |
|---|---|
| S1 출발 전 | "파라다이스 호텔 부산까지 길안내 해 줘" → 내비 경로가 시작됩니다 |
| S2 한 번의 질문 | 카드 "주유하고 세차할까요?" (연료 18% · 세차 36일 전 · 7일 동안 비 없음) |
| S3 대답 | "응, 세차도 할게" → 주유소가 경유지로 들어가고 세차가 예약됩니다 |
| S4 주행 | 조용합니다 |
| S5 주유소 첫 정차 | "세차 입구에서 맞춰 드릴게요" 알림만 |
| S6 세차 입구 정차 | "곧 세차 모드를 켤게요" 카드, 5초 뒤 스스로 시작 |
| S7 맞추는 중 | 창문 닫기 → 와이퍼 끄기 → 내기 순환 → 문 잠금. 사이드미러는 "직접" |
| S8 세차하는 동안 | "세차 모드 켜짐" 한 줄 |
| S9 출발 | D단으로 바꾸면 원래대로 돌리고 "사이드미러 펴졌는지 확인해 주세요" |

### ② 아이 등원길 — 차일드락 (9장면, 약 4분)

유치원으로 길안내 → "아이 타고 있나요? 차일드락 맞춰 드릴까요?" → 뒷창문 잠금(뒷문 차일드락은 "직접") →
주행 중 뒷자리 벨트 풀림 알림 → 유치원 도착하면 잠금 풀기 → 집으로 갈 때 "아침처럼 뒷창문 잠가 드릴까요?" → 집 도착하면 풀기.

### ③ 시트 맞추기 — 시트 메모리 (7장면, 약 3분)

"시트 좀 맞춰 줘" → "앞으로 조금", "등받이 세워 줘"로 조금씩 맞추기 → "됐어" → 이름으로 기억 →
"옆에 희정이 앉았어" → 조수석을 저장된 자세로 맞추기.

## 4. 시연 밖에서 써 보기

- 부르는 카드의 루틴 줄을 누르면 그 루틴이 바로 켜집니다(차가 P단으로 멈춰 있어야 합니다).
- 부르는 카드나 질문 카드가 떠 있는 동안 말로도 됩니다("세차할게", "애 태웠어", "시트 좀 맞춰 줘").
  에뮬레이터는 `-allow-host-audio` 옵션으로 켜야 PC 마이크 소리가 들어갑니다.
- 실제 목적지 검색, 주유소 가격, 날씨 예보는 API 키가 필요해 제출 APK에서는 쓰지 않습니다.
  소스에서 debug 빌드로 확인하는 방법은 [DEVELOPMENT.md](DEVELOPMENT.md) 5장에 있습니다.

## 안 될 때

| 증상 | 해결 |
|---|---|
| 카드가 왼쪽이 아니라 오른쪽 앱 화면 안에 뜬다 | 설치의 둘째 줄(`appops … allow`)을 실행하고 Sunstone을 다시 누릅니다 |
| 길게 눌러도 다음 장면으로 안 넘어간다 | 장면 준비 중입니다. 앱의 말이 끝난 뒤 다시 누르거나, 부르는 카드의 [다음 장면]이 "준비 중"에서 바뀌면 누릅니다 |
| 시나리오 중간에 꼬였다 | 부르는 카드 → [처음] → 시연에서 다시 고릅니다 |
| 앱이 말하지 않는다 | 에뮬레이터·PC 소리를 확인합니다. 음성 엔진 준비가 늦으면 처음 한두 문장은 녹음본으로 나옵니다 |
| 권한을 거절했다 | `adb uninstall com.westone.sunstone` 뒤 처음부터 다시 설치합니다 |
| 기어·속도가 바뀌지 않는다 | 시연 모드는 에뮬레이터 안 Virtual Console로 차 값을 넣습니다. Pleos Connect v2.1.0 에뮬레이터가 맞는지 확인합니다 |

## 알아 둘 것

프로토타입입니다. 시연 모드는 차 상황(기어, 속도, 문, 탑승, 연료, 마지막 세차일, 벨트, 장소)과 주유소·날씨를 장면마다 넣어 줍니다.
**주유소 가격과 세차 가능 여부, 날씨는 준비한 예시 값입니다.** 무엇이 실제이고 무엇이 조작인지는 [README](../README.md)의 "되는 것과 조작한 것"에 있습니다.

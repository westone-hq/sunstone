# 시나리오 ① — 직접 목적지 입력

2026-11-14 변경. 오피넷·가격 비교를 제거하고 카카오 주변 주유소 검색으로 전환했다.

## 사용 순서

1. **① 출장 가는 길**을 누른다. 정차·연료 18%·마지막 세차 36일 전을 준비한다.
2. 앱이 목적지를 물으면 **말 한마디**에 원하는 목적지를 입력한다.
   `서울역`처럼 장소명만 적거나 `강남역으로 안내해 줘`처럼 입력해도 된다.
3. 여러 후보가 있으면 화면에서 선택하거나 번호를 입력한다.
4. Pleos 길안내가 시작된 뒤 연료가 부족하면 현재 위치 주변 주유소를 카카오로 검색한다.
   반경 5km 내 가까운 후보를 선택하며 가격·경로상 최소 우회는 비교하지 않는다.
5. 선택한 주유소 위치의 향후 168시간 날씨를 확인한다.
   - 기준 이상 비 예보 없음: 주유하고 세차 / 주유만
   - 비 예보 있음: 주유소 경유 / 경유 안 함
   - 확인 불가: 세차 추천 보류, 주유소 경유 / 경유 안 함
6. 사용자가 세차에도 동의하고 경유지·도착 감지 등록이 성공하면 내부 세차 모드를 예약한다.
7. 예약 후 **다음 장면**부터 기존 주행 → 첫 정차 → 이동 후 두 번째 정차 → 5초 실행·취소 →
   차량 제어 → D단 복원 흐름을 유지한다.

카카오는 세차 시설 여부를 제공하지 않는다. 가격은 null, 시설은 미확인으로 보관한다.
날씨상 세차를 권할 수 있어도 그 주유소에 세차장이 있다고 단정하지 않고 확인이 필요하다고 안내한다.
시설이 실제로 없는 곳에서 두 번째 정차를 세차 입구라고 확정할 수 없다는 기존 휴리스틱 한계는 남는다.
업체에 실제 예약을 접수하지 않는다.

## 표시·진행

- S1은 목적지 입력·검색·후보 선택·내비 시작 상태를 표시한다.
- S2는 주유소·날씨 조회 및 사용자의 주유·세차 선택 대기를 표시한다.
- 목적지 입력 전이나 선택 대기 중에는 다음 장면으로 건너뛰지 못한다.
- 세차 예약이 생겼을 때만 S3 이후의 세차 시연 단계로 진행할 수 있다.
- 주유만 선택하거나 추천을 거절하면 세차 예약 없이 길안내를 유지한다.
- 후보 이름·주소 전체를 길게 읽지 않고 화면에서 선택하도록 짧게 안내한다.
- 시나리오 ②·③은 기존 대사·준비 흐름을 유지한다.
- 명시적인 debug `scene S번호` 장면 주입은 기존 대사집 재현용으로 남겨 두었다.

## 검증

- routines 99개 통과: 기존 세차·차일드락·시트, 입력 대기, 후보 선택, 가격 없는 주유소,
  거리순 선택, 날씨 3분기, 주유만·세차 예약 여부 검증.
- app 19개 통과. 실제 Open-Meteo 테스트 포함, 건너뜀 없음. routines와 합계 118개 통과.
- 실제 카카오 목적지 검색과 주변 주유소 검색 테스트 모두 통과.
- debug APK 빌드 성공, Pleos 에뮬레이터에 설치 완료.
- 실제 ① 버튼에서 목적지를 자동 입력하지 않고 기다리는 화면 확인.
- `서울역` 입력 → 후보 선택 → Pleos 경로 시작(23km·49분) 확인.
- 실제 카카오 근처 주유소 추천 확인. Open-Meteo의 일시적인 연결 실패 재시도를 추가한 뒤,
  실제 선택한 주유소 좌표에서 7일 비 예보 있음 판정·TTS·주유소 경유 버튼을 확인했다.
  실패 시 확인 불가 분기는 유지한다. 상세 원인과 검증은 [날씨 수정 기록](WEATHER_FIX.md) 참고.
